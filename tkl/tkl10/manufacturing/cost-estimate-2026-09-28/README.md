# v10 cost estimate — 2026-09-28

**Planning estimate: about $165 for five assembled carrier PCBs delivered,
roughly $33 each, before any reverse-LED handling/fixture charge.** This is a
projection from the saved September 26 v9 quote, not a new live v10 quote.
No v10 order was submitted and the cart was not modified.

| Cost for five | Estimated USD |
| --- | ---: |
| PCB fabrication | about 29 |
| Components | about 23 |
| Assembly and setup | about 29 |
| Shipping, duties and taxes | about 84 |
| Total, rounded for planning | about 165 |

Use two-layer 1.6 mm FR-4, lead-free HASL, Economic bottom-only assembly,
lead-free SMT and through-hole solder, lead-free component finishes, and no
paid rail removal. Current matched-part compliance and availability still need
confirmation. JLC's public capability table supports this board size and finish;
reverse-LED acceptance and any processing charge require factory review.

The saved v9 quote was $80.34 merchandise plus $50.24 freight and $32.62
checkout duties/taxes = $163.20, excluding rail removal. V10 has the same seven
BOM groups and board dimensions, with three additional diodes per board.
Fifteen more diodes at the saved $0.0242 each add $0.363; thirty additional SMT
joints at JLC's published $0.0016 rate add about $0.048. All other prices,
overages, stock, shipping and taxes are assumptions until requoted.

The controller clones, switches, battery, case, plate, keycaps, stabilizers and
mechanical hardware are excluded. At the user's reported $4 per clone, five
new modules would add about $20 before any module shipping/taxes.
