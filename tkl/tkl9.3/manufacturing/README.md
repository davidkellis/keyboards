# v9.3 uses the unchanged v9.1 PCB

The plate changes and gains six separate light-window inserts. The v9.2 base
is identical and can be reused. The KiCad files, assembly BOM, placement
file and parts catalog are copied unchanged from v9.1. Do not manufacture an
earlier v9 PCB without the twelve mounting holes.

Use the existing [v9.1 manufacturing handoff](../../tkl9.1/manufacturing/tkl-v9.1-prototype-handoff.zip)
and its ordering instructions. This revision does not create a new JLC quote,
change a cart or place an order. PCB fabrication and assembly requirements are
unchanged; live pricing still depends on JLC's quote. JLC's existing J1 connector
pin tails are modeled at 1.8 mm above the PCB in v9.2; **the user must trim them
to at most 1.0 mm above the PCB** before the closed v9.3 plate is fitted. No
factory lead-trimming service has been ordered or assumed.

The plate is compatible with the v9.1 PCB and v9.2/v9.3 base. Removing the
integrated upper from a v9.1 base would leave its wall
height unfinished.
