# TKL v0: original KiCad project

This is the original keyboard project that preceded the later numbered design
iterations. Its PCB, schematic, and project files are preserved byte for byte.

- Open [tkl.kicad_pro](tkl.kicad_pro) in KiCad.
- [PCB](tkl.kicad_pcb)
- [Schematic](tkl.kicad_sch)

The KiCad project is still named `tkl`; the directory name identifies this
snapshot as v0. See the [repository index](../../README.md) for later revisions.
